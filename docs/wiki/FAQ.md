## 热键与交互

**⌘⇧D 没反应？**
按三态矩阵，主应用在前台可见时快捷键静默失效（只保留一个输入面）。先确认 DSH Desktop 是否正被使用：最小化它或切到别的应用再试。

**⌘⇧D 会不会和别的冲突？**
与系统「显示/隐藏程序坞」（⌥⌘D）已错开。代价是 Launcher 运行期间全局占用 ⌘⇧D——Finder 的「前往桌面」快捷键（⌘⇧D）会被拦截。介意的话改 `Sources/HotKeyCenter.swift` 里的修饰键掩码一行即可。

**迷你框弹出后点了别处就没了？**
设计如此：面板失去按键焦点即收起（点外部、切换应用）。Esc 亦可关闭。

**访达「添加工作区」没反应？**
Launcher 会显式激活自己再拉起面板；若系统焦点被占用瞬间失败，重试一次。持续复现请提 Issue。

## 状态图标

**图标一直是「！」？**
后端未运行。右键 → 启动 DSH Desktop，或直接打开主应用。

**图标「？」闪烁不止？**
有进程占着 3080 端口但不响应桥接健康报文——多半是后端启动中；持续超过一分钟说明端口被陌生服务占用，用一键体检的「端口身份」行确认占用者。

## 迷你对话框

**发送时提示 Node 未就绪？**
后端依赖 Node.js（`/opt/homebrew/bin/node` 或 `/usr/local/bin/node`）。先从 DSH Desktop 正常启动一次后端，之后迷你框可按需代拉。

**展开后打字到很高就滚动了？**
生长上限≈整屏可视高度（保留顶部呼吸）；到底后输入区内部滚动，发送不受影响。

**选择模型里没有「思考强度」分区？**
思考档位由各提供方适配器暴露，部分路由不提供。没有该分区即代表此路由不支持按档调节，走默认推理强度。

## 权限与隐私

**要辅助功能权限吗？**
不需要。Launcher 不使用任何系统权限；与主应用的窗口状态通信用的是分布式通知，与后端的通信全部在本机回环。

**数据去向？**
迷你框发送的文本 → 本机后端 → 你配置的模型提供方，与在主应用里直接对话完全一致。Launcher 自身不收集、不上传任何数据。

## 卸载与残留

**如何彻底卸载？**
右键退出 Launcher → `~/Library/Application Support/DSH Launcher.app` 移入废纸篓。无守护进程、无登录项、无 LaunchAgents。主应用设置页的菜单栏插件区会随卸载自动隐藏。
